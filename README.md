# Insta API

A Flask-based Instagram-style social media application.

## Features

- User registration
- Login/logout
- Password hashing
- Profiles
- Profile pictures
- Create posts
- Edit posts
- Delete posts
- Search users
- View user profiles
- View user posts
- Follow system

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
